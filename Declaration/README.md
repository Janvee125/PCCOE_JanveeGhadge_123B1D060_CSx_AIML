# Declarations Folder

This folder contains editable declaration templates for the capstone submission.

- `student_declaration.md` — student/team declaration template.
- `ai_and_external_tools_disclosure.md` — disclosure of AI assistance, external tools, dependencies, and evaluation limitations.

Before submission:
1. Replace all bracketed placeholders.
2. Verify the official case-study ID.
3. Compare these templates with the official PCCOE forms/instructions.
4. Obtain signatures only where required.
5. Do not claim institutional approval unless it has been granted.
